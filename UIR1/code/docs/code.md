# Документация к коду УИР 1

## Запуск

Из папки `UIR1/code`:

```bash
python main.py
```

Нужны `numpy` и `matplotlib`. Исходные данные читаются из `UIR1/210_variant.txt`.

## Порядок работы `main.py`

1. `load` читает 300 значений, десятичная запятая заменяется на точку.
2. `characteristics` считает характеристики для первых n значений, n = 10, 20, 50, 100, 200, 300.
3. По среднему и коэффициенту вариации выборки из 300 значений `hypoexp_params` находит параметры `t1`, `t2`.
4. `hypoexp_generate` генерирует 300 значений с зерном `SEED = 42`.
5. Для сгенерированной последовательности повторяется пункт 2.
6. `autocorrelation` считает коэффициенты автокорреляции обеих последовательностей для сдвигов 1-10, `pearson` - их взаимную корреляцию.
7. Функции из `tables.py` сохраняют формы 1-3 в `report/tables/*.tex`.
8. Функции из `plots.py` сохраняют 7 графиков в `report/figures/*.png`.
9. Численные результаты сохраняются в `output/results.json`, сгенерированная последовательность в `output/generated.txt`.

Константы в начале `main.py`:

| Константа | Значение | Назначение |
|-----------|----------|------------|
| `SIZES` | 10, 20, 50, 100, 200, 300 | объёмы выборок |
| `N_BINS` | 10 | число интервалов гистограммы |
| `SEED` | 42 | зерно генератора, делает результат воспроизводимым |

## `uir1/stats.py` - статистика

### `characteristics(x)`

Возвращает словарь с оценками по массиву `x`:

| Ключ | Формула | В коде |
|------|---------|--------|
| `mean` | m = Σxᵢ / n | `x.mean()` |
| `var` | D = Σ(xᵢ - m)² / (n - 1) | `x.var(ddof=1)` |
| `std` | σ = √D | `np.sqrt(var)` |
| `cv` | ν = σ / m | `std / mean` |
| `ci[p]` | ε_p = t_p · σ / √n | `t * std / np.sqrt(n)` |

Деление на n - 1 даёт несмещённую оценку дисперсии.

Доверительный интервал для математического ожидания равен m ± ε_p. Выборочное среднее по центральной предельной теореме распределено примерно нормально, поэтому t_p = Φ⁻¹((1 + p) / 2), где Φ⁻¹ - функция, обратная функции Лапласа. Значения t_p не вычисляются, а взяты из таблицы методички и хранятся в словаре `T_P`:

| p | t_p |
|---|-----|
| 0,90 | 1,643 |
| 0,95 | 1,960 |
| 0,99 | 2,576 |

### `rel_dev(value, reference)`

Относительное отклонение в процентах со знаком: (value - reference) / reference · 100. В таблицах отчёта берётся модуль.

### `pearson(x, y)`

Коэффициент корреляции Пирсона:

r = Σ(xᵢ - x̄)(yᵢ - ȳ) / √(Σ(xᵢ - x̄)² · Σ(yᵢ - ȳ)²)

### `autocorrelation(x, max_lag=10)`

Для каждого сдвига k = 1…10 считает `pearson(x[:-k], x[k:])`, то есть корреляцию между последовательностью и ею же, сдвинутой на k позиций.

## `uir1/distribution.py` - закон распределения и генератор

### `hypoexp_params(mean, cv)`

Гипоэкспоненциальная величина - сумма двух независимых экспоненциальных величин со средними t₁ и t₂. Параметры подбираются так, чтобы совпали математическое ожидание t и коэффициент вариации ν:

- t₁ + t₂ = t;
- t₁² + t₂² = ν²t².

Решение этой системы: t₁,₂ = t/2 · (1 ± √(2ν² - 1)). Оно существует только при 1/√2 ≤ ν < 1, иначе функция выбрасывает `ValueError`. Для варианта 210 ν = 0,8776, t₁ = 85,516, t₂ = 13,063.

### `hypoexp_pdf(x, t1, t2)`

Плотность суммы двух экспонент, то есть их свёртка:

f(x) = (e^(-x/t₁) - e^(-x/t₂)) / (t₁ - t₂), x ≥ 0.

Используется на графике сравнения плотности с гистограммой.

### `hypoexp_generate(t1, t2, size, rng)`

Генератор работает в три шага:

1. `rng.random(size)` выдаёт равномерно распределённые числа r на [0; 1). `rng` - это `np.random.default_rng(SEED)`, библиотечный генератор numpy на алгоритме PCG64.
2. Метод обратной функции превращает r в экспоненциальную величину. Функция распределения экспоненты F(x) = 1 - e^(-x/t). Из уравнения F(x) = r получается x = -t · ln(1 - r).
3. Две такие величины со средними t₁ и t₂ складываются:

X = -t₁ · ln(1 - r₁) - t₂ · ln(1 - r₂)

Поскольку r < 1, выражение 1 - r всегда больше нуля и логарифм определён.

Проверка на 100 000 значениях даёт среднее `98,506` и коэффициент вариации `0,8748` при заданных `98,578` и `0,8776`.

## `uir1/tables.py` - таблицы отчёта

| Функция | Что строит |
|---------|------------|
| `form_values(sizes, chars)` | формы 1 и 2: значения характеристик по объёмам выборок |
| `form_deviations(sizes, chars, refs)` | модули относительных отклонений от `refs` в процентах |
| `form_acf(acf_given, acf_gen)` | форма 3: автокорреляция обеих последовательностей и различие в процентах |
| `num(v, d)` | число с `d` знаками, десятичной запятой и минусом в формате LaTeX |

Для формы 1 эталон `refs` - характеристики выборки из 300 значений. Для формы 2 эталон - характеристики исходной последовательности того же объёма.

Порядок строк таблиц задаёт список `ROWS`.

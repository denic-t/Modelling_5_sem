# УИР 1. Обработка результатов измерений: статистический анализ числовой последовательности

Вариант 210

## Задание

По заданной последовательности из 300 значений нужно:

1. Рассчитать математическое ожидание, дисперсию, с.к.о., коэффициент вариации и доверительные интервалы для выборок из 10, 20, 50, 100, 200 и 300 значений.
2. Определить характер последовательности по графику значений.
3. Выполнить автокорреляционный анализ и оценить, случайна ли последовательность.
4. Построить гистограмму распределения частот.
5. Аппроксимировать закон распределения по двум начальным моментам.
6. Сгенерировать последовательность по полученному закону и сравнить её с исходной.
